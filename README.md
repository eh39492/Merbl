# Merbl
Making a marble run! So fun!

It's a marble run made for Half-Life Week 2. It is made entirely in Onshape using tools like sweep, sketch, and extrude. 
<img width="890" height="747" alt="Screenshot 2026-10-18 114644" src="https://github.com/user-attachments/assets/c685f9a3-3067-4962-9140-64534189c38e" />
ik its very short track, but I am a beginner, so it was really hard for me to do. features a jump and a few drops. I used Onshape and all the standard tools like sweep, sketch, and planes.

The ball will start at the top of a steep ramp, then go through a twisty area, then down a switchback into a jumps and a fallback to the finish.

The ball has a 6mm diameter (subject to change)
The model is 197.4 x 138.4 x 152.6mm
